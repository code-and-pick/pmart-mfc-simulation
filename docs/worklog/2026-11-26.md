## 이동할 때 가끔 느려지는 것 — 셰이더 미리 만들기 · 칸 번호 나눠 그리기
- 요청: 성능 패널 수치(FPS 36, 프레임 p95 109 ms, GPU 17.6 ms > CPU 5.9 ms, 긴 작업 1초에 3회 230 ms)와 함께 "이동할 때 가끔씩 느려지는데 화면이나 기능에 문제 없게 빨라질 수 있는 방법 있나?" → 제안 1·2·3 중 "1,2번만"(3 그림자 두 장에 한 번은 안 함).
- 잰 것: headless MOCK 에서 확대 뒤 오른쪽 끌기로 이동하며 CPU 프로파일 + shaderSource 가로채기. 이동 중 MeshBasicMaterial 셰이더 2개(USE_COLOR, DoubleSide 투명)를 그 자리에서 만듦(getShaderInfoLog·getProgramInfoLog 합 약 2.4 s, swiftshader 기준). 원인 = 인스턴스 묶음의 instanceColor 가 첫 setColorAt 때 생겨 셰이더 종류가 바뀜(피킹 목표 고리 등). 이름표 정리·칸 번호·패널 다시 그리기는 작았음.
- 고침:
  1. `SiteScene.tsx` Precompile: 연 뒤 1초·6초에 장면 전체(숨은 것까지 잠깐 보이게)를 `gl.compileAsync` 로 미리 만들고, 색 없는 InstancedMesh 에 흰색 instanceColor(곱해도 원래 색)를 미리 붙임 → 이동 중 셰이더 만들기 0개(다시 잰 결과 `shaders []`).
  2. `locationLabels.ts`: 칸 번호를 한 장에 최대 20개(PLACE_PER_FRAME)만 새로 그려 올리고 남으면 다음 장에 이어서. 전엔 0.2초마다 최대 160개를 한 장에.
- 검증: tsc·vitest 224·build 통과. MOCK 캡처(전체·가까이)로 색·칸 번호 그대로 확인. 실제 GPU 수치는 사용자 성능 패널로 다시 비교 필요(headless 는 CPU 그리기라 시간 값은 실제와 다름).
