# 백엔드에서 온 것 (backend → simulator)

> 백엔드 작업(pmart-backend)이 2026-11-09 사용자 요청으로 남긴 안내. 정본은 백엔드 저장소에 있고, 여기는 **어디를 읽으면 되는지와 요약**만 둔다.
> 시뮬레이터 → 백엔드 요청은 지금처럼 `docs/backend-requests.md`(R-xx).

## 어디를 읽나 (`../pmart-backend`)

| 무엇 | 위치 |
|---|---|
| 백엔드 → 시뮬레이터 공지·회신 | `docs/handoff/simulator/` (첫 공지 `2026-11-09-simulator-notice-integration-decisions.md` — R-01~R-12 현황 포함) |
| **시험 센터 칸 = 이 시뮬레이터 평면**(코드 대응·새 필드·고회전 칸) | `docs/handoff/simulator/2026-11-09-simulator-notice-layout-bins.md` |
| 고회전 칸 목록(백엔드·시뮬레이터 코드, 랙, 좌표) | `docs/simulator/mfc/layout/high-turnover.json` |
| 실서버·실제 앱 연결 목표와 결정(SIM-1~11) | `docs/simulator/mfc/mfc-simulator-integration.md` |
| 이 시뮬레이터 평면을 그린 도면 | `docs/simulator/mfc/layout/` (`buildLayout()` 실행 좌표로 그림, `floorplan.svg` — 고회전 랙은 빨간색) |
| 백엔드 클라이언트 handoff(PDA 앱 등) | `docs/handoff/clients/` (2026-11-09 폴더 이동) |

## 목표 (사용자 2026-11-09)

개발 환경에 실제 MFC 현장이 없으니 **시뮬레이터가 현장을 대신해 보여 준다.** 평소에는 가짜 데이터로 돌고, 실제 앱(고객 앱 주문·PDA 작업)에서 생기는 사건도 같은 화면에서 처리한다. 특정 작업자는 실제 PDA 앱이 조종한다. **백엔드 계약이 정본이고, 안 맞는 부분은 시뮬레이터가 맞춘다.**

## 결정 요약 (2026-11-09, 세부는 백엔드 문서)

| ID | 결정 | 시뮬레이터가 할 일 |
|---|---|---|
| SIM-1 (임시) | 실서버 모드는 1× 실제 시간, 센터 시간 설정 없음 | 배속은 MOCK 모드 전용 |
| SIM-2 | 실제 작업자는 로그인 + 권한으로 구분 | 자기 가상 작업자 계정만 움직이고, 나머지 작업자는 실제 사람으로 표시 |
| SIM-2a | 실제 작업자는 **마지막 버튼 기준**으로 추적 | 배정·작업 상태·피킹 칸·이동 집기/내려놓기를 조회해 마지막 칸 앞에 표시 |
| SIM-3 | 가상 작업자 = 시뮬 센터 전용 실제 운영자 계정(`MFC_WORKER`) | 로그인 API 로 토큰 받기(R-02 회신) |
| SIM-4 (임시) | 실서버 모드에서 가짜 주문 없음(실제 고객 앱 주문만) | 가짜 주문은 MOCK 모드에서만. 나중에 실서버 가짜 주문 필요(SIM-4a, 방식 미결) |
| SIM-5 | 변화 수신 = 주기 조회(시작 3초) | 재고는 작업에 나온 SKU 만·바뀔 때만, SKU 전체 반복 조회 금지 |
| SIM-6 | 센터·위치·재고는 백엔드 기준(`MFC-SEED-01`). **보완(같은 날)**: 도면 = 이 시뮬레이터 평면, 백엔드 칸을 평면대로 다시 등록(6,762칸·좌표·치수) | 칸 코드를 백엔드 문법으로 바꿔 매기기: `A01-01-101` → `F-A1-01-1-01`(`{온도대 A/C/F}-{그룹 글자+줄}-{랙}-{단}-{칸}`) |
| L-1 | 선반 칸은 **일반 선반(임시)**, E2E 시험용 고회전 칸만 5개 | 이 5칸 `H01-01-101`~`104`·`H01-01-201`(백엔드 `A-H1-01-1-01`~`04`·`A-H1-01-2-01`)을 고회전으로 표시 |
| SIM-7 | 라이더: 배송 서비스 전까지 실서버는 출하 대기까지 | 인계는 MOCK, 배송 구현 뒤 라이더 시험 계정(R-07 회신) |
| SIM-8 | 가짜 실적 구분 = 시뮬 센터·시뮬 계정 | 별도 출처 필드 없음(R-03 회신) |
| SIM-9 | 실행 끝에 API 로 정리 | 열린 작업 중지·복귀, 되돌리는 이동(본보기 백엔드 `deploy/lan/checks/mfc_e2e.py`) |
| SIM-10 | LAN 서비스 배치 그대로 | 가상 작업자 수는 조회 부하 보며 늘리기 |
| SIM-11 | Vite 개발 서버 프록시로만 접속 | 가상 작업자 비밀번호는 Vite 서버 쪽 비밀 파일(Git 금지), 브라우저에는 토큰만 |

용어: 백엔드는 "감독자"를 **센터 관리자**로 부른다(역할 코드 `MFC_SUPERVISOR` 그대로).
